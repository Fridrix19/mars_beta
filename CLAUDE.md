## Что это

**Marscap** — редизайн магазина store.marscap.ru: каталог зарубежных цифровых сервисов (139 штук: нейросети, дизайн, игры, развлечения, работа, зарубежные покупки) и виртуальные долларовые карты для оплаты подписок. Клиент пополняет рублёвый баланс через СБП и покупает с баланса; оператор выдаёт заказ в админке.

Владелец — заказчик проекта, общается по-русски. **Отвечай всегда по-русски**, коротко и по делу.

Юрлицо (в подвале каждой страницы и в «Контактах»): **ООО Марс Капитал «Цифровые Решение», ИНН 9715523083** — написание «Решение» по указанию владельца. ОГРН и адрес нужно уточнить у него. Задаётся в `build/build.py` → `LEGAL`.

- `web/` — сервер: Nuxt 4 + Nitro + PostgreSQL 16, API `/api/*`, админка `/admin` (Vue + PrimeVue 4.5). Миграции — `web/server/db/migrations/001…013`.
- `source-site/` — снимок исходного сайта: логотипы, каталог (`search.js`), тарифы (`payment-flow.v2.js`). Логотипы сервисов не менять без согласия владельца. SVG крупнее 20 КБ подключаются файлом `/assets/services/…`, мелкие встраиваются.
- `design-system/` — дизайн-система отдельным пакетом.

## Команды

```bash
# сайт
python build/build.py           # все страницы, кроме страниц сервисов (быстро)
python build/build.py all       # всё, включая 139 страниц сервисов
python build/build.py chatgpt   # только указанные сервисы

# сервер
cd web
npm ci
set NUXT_DATABASE_URL=postgres://user:pass@localhost/marscap   # PowerShell: $env:NUXT_DATABASE_URL="..."
set NUXT_SECRET=любая-длинная-строка
set NUXT_STAND=true              # стенд/разработка: тестовая оплата, коды на экране, admin/admin. В бою НЕ задавать
set NUXT_DEV_CODES=true          # коды из писем показываются на экране (только со NUXT_STAND)
npm run migrate                  # миграции + админ admin/admin (на стенде) или ADMIN_BOOTSTRAP_PASSWORD (в бою), если админов нет;
                                 # на стенде ещё тестовые аккаунты из TEST_ADMIN_LOGIN/PASSWORD и TEST_USER_LOGIN/PASSWORD
npm run build && npm start       # http://localhost:3000, админка /admin

# тесты (сервер должен быть запущен)
set DATABASE_URL=... & set API_URL=http://localhost:3000 & npm test   # 25 тестов, все должны проходить
```

Сборке нужны Python 3.10+ и Node 20+ (глобально установленный `sharp` — только для крупных SVG-логотипов).

## Дизайн (требования заказчика)

- Тёмно-синяя палитра, фон `#090D18`; светлая тема по переключателю (`html[data-mc-theme="light"]`, выбор в `localStorage('mc-theme')`).
- Фон — «галактика» `build/galaxy-bg.v58.js` в слоте визуала; на странице сервиса галактика вместо картинки.
- Шрифты: Onest — заголовки, Golos Text — текст, JetBrains Mono — только цифры, кикеры — Inter 600 без черты.
- Карта в первом экране главной — 3D, вращается и левитирует. Активный пункт шапки — «утопленная» тёмная плашка с объёмным текстом.
- Логотип сервиса стоит в строке с заголовком h1, без рамки и подложки; светлые логотипы в плитках — на тёмной подложке (`build/icon-lum.json`).
- Кнопки в подвале карточек — во всю ширину. Страница раздела показывает только свою категорию.
- Мобильная версия (≤760 px): вместо шапки — `.m-top`, снизу таббар (Каталог / Карта / Как это / Поддержка / Ещё) и лист «Ещё».
- На всех страницах есть хлебные крошки и кнопка «← Назад» (по истории браузера, если пришли с сайта, иначе на уровень вверх); в кабинете экраны пишутся в историю браузера, в админке крошки — `web/app/components/AdmCrumbs.vue`.

## Деньги и цены (не ломать)

- Цены 1:1 с исходным сайтом. Комиссия: до $45 — (сумма + 5) × 1.2, выше — × 1.3; итог × курс ЦБ (в прототипе 80.2254, на сервере — живой курс ЦБ с наценкой, если включён автокурс в админке).
- Модель цены сервиса: `payment-flow.v2.js` → `src/pages/static-models.json` → дефолт раздела.
- Виртуальная карта: номиналы 50/75/100/150/200 $, произвольная сумма $50–200.
- Баланс — только через проводки `ledger_entries` и SQL-функции (`place_order`, `payment_succeeded`, `refund_order` …). Суммы — целые копейки/центы. Цена и курс фиксируются в заказе. Номер заказа `MC-XXXXXXXX`.
- Без верификации (KYC) — покупки сервисов до 15 000 ₽ в месяц; **выпуск виртуальной карты (и в подарок) — только после одобренной верификации** (`prepareOrder`). В заявке: ФИО, вид документа, телефон и/или почта, фото документа и селфи; после одобрения ФИО и телефон переносятся в профиль. За верификацию бонус 500 ₽.
